Менеджер AmneziaWG 2.0 — разверни VPN на VPS одной командой.

🚀Быстрый старт
sudo curl -fsSL https://raw.githubusercontent.com/pumbaX/awg-multi-script/main/awg2.sh -o /usr/local/bin/awg2 && sudo chmod +x /usr/local/bin/awg2 && sudo awg2
🎁Запуск в любой момент
sudo awg2

♠️ ИНСТРУМЕНТЫ ДЛЯ AMNEZIAWG

Анализатор конфигов
https://pumbax.github.io/awg-analyzer/
Проверяет параметры обфускации, устойчивость к DPI и общую безопасность
конфигурации. Работает полностью в браузере, ничего никуда не уходит.

Генераторы обфускации
▪️ AmneziaWG Architect — конструктор
https://vadim-khristenko.github.io/AmneziaWG-Architect/
▪️ Special Junk Packet List — наборы junk под разные DPI
https://voidwaifu.github.io/Special-Junk-Packet-List/
▪️ Amnezia Signature Generator
https://spatiumstas.github.io/junker/
▪️ PayloadGen
https://sketchystan1.github.io/payloadGen/
▪️ Mini QUIC Generator
https://sageptr.github.io/mini_quic_generator/
⚠️ Параметры S1-S4 и H1-H4 должны совпадать с сервером, иначе туннель
поднимется, но трафик ходить не будет.
